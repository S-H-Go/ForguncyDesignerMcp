# 活字格设计器 MCP 扩展

面向活字格设计器的独立 MCP 扩展：在本机发现和读取工程模块，并通过匹配版本的设计器应用、保存和回读受支持的修改。此项目不是活字格官方产品。

## 支持范围

- 适配器目标：活字格 11.0.3.0、11.0.104.0 和 12.0.102.0。仅凭主版本号相同不能判断兼容；未知构建不应强行启用写入。
- 以实际连接后返回的工具目录和工程能力为准。对工程的修改不替代开发预览、业务验证或部署验收。
- 协同操作以设计器当前绑定的原生登录身份和锁归属为准。客户端可提供预期身份用于核对，不能借此冒用身份。无法确认身份或状态时，不继续写入。

## 构建

需要 Windows、支持 .NET 8 目标的 .NET SDK 和有权使用的活字格设计器安装。仓库不附带厂商 SDK、类型声明、设计器安装包或插件二进制包。

从仓库根目录运行（将路径替换为实际安装目录）：

```powershell
dotnet build .\ForguncyDesignerMcp\ForguncyDesignerMcp.csproj -c Release -m:1 -nr:false -p:UseSharedCompilation=false "-p:ForguncyRoot=C:\ProgramData\Forguncy 12"
```

上述命令只构建，不会自动安装插件。按目标版本的活字格插件打包和安装流程自行处理构建产物；不要复制或分发来自设计器安装目录的厂商 DLL。源码构建通过不等于已验证每个版本的设计器内安装和实际协同工程。

## 连接和操作

在已按对应版本正确安装扩展的设计器中，使用「MCP 服务启动器」辅助单元格和托盘入口查看本机连接信息。仅连接可信客户端，不对外暴露本机服务或分享连接凭据。

先核对当前工程、文档会话和工具能力，再读取目标修订。对异步写入，用返回的原操作 ID 查询最终结果；应用到内存不等于已保存，必要时显式保存并回读源文件。遇到结果不明，不要直接重复提交。

### 开发预览（独立 MCP）

在连接的实时能力目录确认 `preview.start` 已登记，再读取 `project.snapshot`。只对已授权且干净的目标文档发起预览，不会先替调用方保存未保存的修改。

调用 `invoke_api`：`namespace` 为 `preview`、`method` 为 `start`；`parameters` 包含新的 UUID `operationId`、从快照复制的 `target` 与 `expectedProjectRevision`（快照的 `revision`）。用 `project.get_operation` 按原 `operationId` 查询；终态 `succeeded` 时取 `result.url`。仅返回不含用户信息、查询串或片段的本机回环地址；其他地址报告为未确认，不会重试运行。运行中的回执不代表 URL 可访问；用同一台电脑验证 HTTP 和页面行为。

该功能调用设计器本机原生运行入口，不访问厂商 MCP，也不是发布站点。原生运行可能写入本机预览产物，或对已保存文档执行原生收尾。旧插件没有此能力时不要照搬厂商接口或重复启动。
